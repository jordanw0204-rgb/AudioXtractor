# AudioXtractor icon

Generated with the built-in image generation tool using the imagegen skill. The source is saved in `assets/AudioXtractor-icon.png`; compiled 16, 32, 48 and 128 px PNGs are in `extension/icons/`. The generated original is retained. The build prepares extension sizes with Windows System.Drawing; checked-in PNGs support builds elsewhere.

Final generation prompt:

> Create one finished browser-extension app icon for AudioXtractor. Square 1024x1024 image. Minimalist, precise, flat vector-like monochrome brand mark on a uniform very dark charcoal background (#18181c). A single crisp warm-white abstract symbol that combines an A, a sound waveform and a downward extraction gesture; prioritize a beautiful instantly legible geometric silhouette over literal detail. Strong continuous strokes, generous negative space, centered with ample safe margins so it remains clear at 16x16 pixels. Restrained black, dark gray and white only. No words, no lettering, no text, no border, no mockup, no shadow, no glow, no gradient, no extra symbols. The icon should feel sleek, quiet and modern and fit a black/charcoal audio tool.
